# Profile Fields Reference

What each file holds and which funders ask for it. Use when deciding what to
prioritize in a partially complete profile.

## Blocking fields

Without these, most applications cannot be submitted at all. Fill first.

| Field | File | Needed by |
|---|---|---|
| Legal name (exactly as on IRS letter) | organization.md | Everyone |
| EIN | organization.md | Everyone |
| 501(c)(3) determination letter | documents.md | Nearly everyone |
| Current operating budget | financials.md | Nearly everyone |
| Mission statement | organization.md | Everyone |
| Authorized signatory | organization.md | Everyone |
| Most recent 990 | documents.md | Most foundations |

## Federal-only fields

Federal applications need infrastructure that takes weeks to obtain. Check
these before committing to a federal deadline.

| Field | File | Notes |
|---|---|---|
| UEI (Unique Entity ID) | organization.md | From SAM.gov |
| SAM.gov registration | documents.md | Annual renewal; allow 4+ weeks |
| Grants.gov account with AOR role | documents.md | Authorization takes days |
| NICRA or de minimis indirect rate | financials.md | Affects the budget |
| Single Audit status | financials.md | Required above the federal expenditure threshold |

Confirm current thresholds and rates at the time of application rather than
relying on a figure stored here — they change.

## Fields that go stale

Re-verify anything on this list older than a year before using it in an
application.

- Operating budget — annually, at board approval
- Revenue mix — annually, after the audit or 990
- People served — annually
- Program outcomes — per reporting cycle
- Board roster — after each election
- Staff count — quarterly
- Insurance, registrations, SAM.gov — per their expiry dates

## Fields where precision matters

Funders cross-check these against public records. A mismatch reads as
carelessness at best.

- **Legal name** — must match the IRS determination letter character for
  character, including "Inc.", commas, and "The".
- **EIN** — format as `XX-XXXXXXX`.
- **Founding year** — match the articles of incorporation, not the year the
  program started.
- **Budget figures** — must match the 990 or audit for the year cited. State
  which document and year the figure comes from.
- **Address** — must match SAM.gov and the IRS record for federal applications.
